# Backend API

Every request requires `Authorization: Bearer <deployment token>`. Use HTTPS in the Android client. No redirects are followed to avoid credential forwarding. The sample service is single-tenant.

## POST /jobs

Content-Type `application/zip`, known Content-Length, total at most 50 MiB. Archive contains `manifest.json` and 1–20 files named `input-N.ext`. Names are generated by the client; original display names never enter server paths. Detection validates contents, not just suffixes. Expanded upload entries are capped; nested Office archives are checked before parsing.

```json
{
  "files": ["input-0.docx"],
  "options": {
    "target": "pdf",
    "pages": "",
    "pageSize": "A4",
    "orientation": "portrait",
    "sheets": "",
    "range": "",
    "language": "eng",
    "imageMode": "ocr",
    "background": "#FFFFFF",
    "rotations": [0]
  }
}
```

Returns HTTP 202: `{"id":"<32 lowercase hex characters>"}`. At most two processing jobs run simultaneously; otherwise 503. Jobs run in separate process groups. Source size is limited to 50 MiB. The Android app routes its supported local conversions locally instead of uploading them.

## GET /jobs/{id}

Returns `{"state":"running","message":"Rendering with LibreOffice"}`, `{"state":"failed","message":"..."}`, or:

```json
{
  "state": "done",
  "file": "result.xlsx",
  "size": 1234,
  "warnings": ["Review extracted cells."],
  "preview": [{"sheet":"Table 1","rows":[["Item","Price"],["Apple","10"]]}]
}
```

These are actual stages, not synthetic percentage estimates. Preview arrays contain bounded portions of tables; converted XLSX files contain full extracted data.

## GET /jobs/{id}/result

Binary file, application/octet-stream, explicit Content-Length. Download once. After transfer (including broken connection), deletes all job files. A network failure requires reconversion; range/resume is not supported.

## DELETE /jobs/{id}

Kills the process group, deletes files, returns `{"state":"cancelled"}`. Idempotent. Unknown/expired status/result IDs return 404. Disconnected jobs expire after 15 minutes, with a 10-second sweep interval. Active processing stops after 180 seconds, also checked on that interval.

Error bodies use `{"message":"helpful message"}`. Server access logging is disabled; worker stdout/stderr are not logged. No document contents or filenames are written to external logs. The configured token and job IDs must be treated as secrets; use a trusted deployment.
